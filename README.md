# Mentor AI MVP

Chat with world-class mentors powered by AI. Andrew Tate, Gary Vee, Dan Pena, Tai Lopez, and more.

## Project Structure

- `index.html`: The landing page of the application.
- `character-ai/`: The chat application.
- `vercel.json`: Vercel routing configuration for rewrites.
- `api/env.js`: Vercel serverless function to serve environment variables.
- `server.py`: Local unified dev server to run the entire project locally.

## Running Locally

To run the project locally, run:
```bash
python server.py
```
And navigate to `http://localhost:8000/`.
